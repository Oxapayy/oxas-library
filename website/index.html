Choose the stream

See the available servers, languages and quality before you press play. Live channels have their own IPTV tab.

Provider-assisted requests and unencrypted HTTP streams each have their own opt-in. Availability can vary between providers.

Install on iPhone

  1. Download the IPA from GitHub Releases.
  2. Import it into ESign or your preferred sideloading tool.
  3. Sign with your own valid certificate and profile, then install.
  4. Connect your source. Sign in only if you want sync.

Keep the same bundle identifier and signing identity when updating to retain your saved library.

Release notes & checksum

Before you download

Does the app include films or TV?

No. Oxa’s Library is a player for sources you add. You are responsible for having permission to access and download their media.

Do I need an account?

No. You can use a local library. Email sign-in is optional and enables library sync. Apple and Google sign-in are not included.

Will every stream download?

No. Offline saving needs a compatible, permitted file or HLS stream. Provider restrictions, expired links, DRM and incompatible codecs can prevent playback or downloads.

Can I use my server away from home?

Only if the server is reachable from that network. An Oxa account syncs connection settings; it does not expose a private home server to the internet.

What happens if I reset my password?

Your watchlist and viewing history remain. Encrypted server connections must be connected again. A normal password change keeps the existing encryption key.

Where are macOS and Windows?

Both are coming soon. The current downloadable app is for iPhone. No desktop release date is announced.
