Install in a few steps.

The apps are free and open source. They aren’t signed by Apple or Microsoft yet, so your system may ask you to confirm once.

Mac

  1. Choose Apple Silicon for Macs with an M-series chip, or Intel for older Macs.
  2. Open the disk image and drag Oxa’s Library to Applications.
  3. If macOS asks, allow the app in System Settings › Privacy & Security.
  4. Add a source, or sign in to sync your library.
Release notes and checksums ›

iPhone

  1. Download the IPA on your iPhone or computer.
  2. Import it into ESign or AltStore Classic.
  3. Sign it with your own certificate and install it.
  4. Keep the same signing identity for updates so your library stays in place.
Release notes and checksum ›

Windows

  1. Download and run the installer. It picks x64 or ARM64 for you.
  2. If Windows shows a security prompt, choose More info › Run anyway.
  3. Open Oxa’s Library and add a source, or sign in.
Release notes and checksums ›

Web

  1. Open the web app in a current browser.
  2. Continue as a guest, or sign in to bring your library.
  3. Downloads stay in the apps. Many hosted servers open on their own site.
